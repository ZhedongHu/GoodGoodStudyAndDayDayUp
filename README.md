# 初中阶段学习资料分享
## 概述
思考再三，还是打算公开自己的学习资料，包括学习笔记、资料图片、练习题等，我希望以此帮助到更多人。  
我会在**有空时**，抽时间整理自己的资料，并上传到这里。我会尽量保持更新节奏，但是如果哪一天停止更新，或者更新很慢，请不要怪我，**因为我也是学生，我在利用自己的空闲时间做这件小事**。  
我还会定期将所有资料压缩、打包，制作成发行版，方便大家及时下载最新资料。

## 结语
虽然大家都是竞争对手，将我自己的学习资料分享出来，也许对我自己不利，但是，**模仿就只能落后，创新与思考才能领先**，真正优秀的人没有这些资料依然优秀，能力稍逊的人看了资料也不太可能完全超过我。今天的教育已经和曾经不一样了。教育已经不再是教学生怎么应付考试，而是学会解决问题的能力。**能被使用文字记录、分享的知识和能力，只占整个教育阶段所学全部知识的很小一部分**。 不要奢求完成一本本教辅资料、上完一个个培训班就能突飞猛进，不要这样想。  
公开在GitHub看起来会非常奇怪，但是我喜欢这样。另外，这个项目暂时不会放到GitHub个人介绍页面、个人主页网站，目的就是想给真正关心我、想了解我的人一个惊喜。
